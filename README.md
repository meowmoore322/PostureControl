# PostureControl

Бесплатное десктопное приложение с открытым исходным кодом для Windows, которое помогает сохранять правильную осанку во время работы за столом. Программа анализирует видеопоток с веб-камеры, установленной сбоку, с помощью локального ИИ (**MediaPipe**) без отправки данных в сеть.

## Основные возможности
- **100% локальная работа:** кадры с камеры обрабатываются только на вашем ПК.
- **Адаптивные режимы:** *Программирование / ПК*, *Чтение* и *Письмо* с разными допустимыми углами наклона спины и шеи.
- **Ненавязчивые уведомления:** всплывающее окно в углу экрана со звуком срабатывает только при длительной сутулости.
- **Статистика за день:** подсчёт времени с ровной спиной, времени сутулости, напоминаний и активности по режимам.

## Быстрый запуск (без установки Python)
1. Перейдите в раздел **[Releases](../../releases)** справа на странице репозитория.
2. Скачайте файл **`PostureControl_v1.0.0.exe`**.
3. Запустите скачанный файл двойным кликом.

---

## Запуск из исходного кода
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/meowmoore322/PostureControl.git
   cd PostureControl
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Запустите программу** *(файл модели `pose_landmarker_lite.task` уже включён в репозиторий)*:
   ```bash
   python main.py
   ```

## Как пользоваться
1. Расположите веб-камеру сбоку от рабочего места так, чтобы в кадре были видны ухо, плечо и бедро.
2. Выберите текущий режим деятельности в верхнем меню.
3. Нажмите **«▶ Старт»** и следите за прогрессом на вкладке **«Статистика»**.
