# PostureControl

Локальное приложение с открытым исходным кодом для Windows, которое отслеживает осанку через веб-камеру сбоку с помощью ИИ (MediaPipe) без отправки данных в сеть.

## Запуск через `.exe` (без Python)
1. Перейдите в раздел **[Releases](../../releases)**.
2. Скачайте **`PostureControl_v1.0.0.exe`**.
3. Запустите файл двойным кликом.

## Установка и запуск из исходного кода
1. **Скачайте проект:**
   ```bash
   git clone https://github.com
   cd PostureControl
   ```
2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Убедитесь, что в папке лежит модель ИИ:**
   Файл **`pose_landmarker_lite.task`** должен находиться рядом с `main.py` ([скачать модель](https://googleapis.com)).
4. **Запустите программу:**
   ```bash
   python main.py
   ```

## Использование
1. Поставьте камеру сбоку так, чтобы в кадре были видны ухо, плечо и бедро.
2. Выберите режим (*Программирование / ПК*, *Чтение* или *Письмо*).
3. Нажмите **«▶ Старт»**. Статистика за день сохраняется во вкладке **«Статистика»**.
